Welcome. This is the first post on the blog — mostly a placeholder so the site
has something to render, but also a small commitment device to actually write
more.

## What this is

A plain static site, built with [Astro](https://astro.build/) and deployed to
GitHub Pages. Posts live as Markdown files in the repo, which means:

- Writing is just `git commit`
- Everything is version-controlled
- No database, no CMS, no account to forget the password to

## What to expect

Short notes, longer write-ups when something is worth writing up, and the
occasional half-finished experiment. Tags will sort themselves out as things
accumulate.

If you want to follow along, there's an [RSS feed](/rss.xml).
